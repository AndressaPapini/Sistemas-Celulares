## 01. SOBRE O PROJETO

<table>
<tr>
<td width="65%" valign="top">

### Uma nova forma de organizar atendimentos

O **Sistemas Celulares** é uma aplicação web desenvolvida para auxiliar no gerenciamento de uma assistência técnica de dispositivos móveis.

Seu objetivo é centralizar informações importantes em um único ambiente, tornando as atividades administrativas mais organizadas, acessíveis e eficientes.

A aplicação reúne conceitos de desenvolvimento web, programação e modelagem de banco de dados.

</td>

## 07. COMO EXECUTAR

<div align="center">

### Comece a explorar o sistema

*Siga as etapas para preparar o ambiente de desenvolvimento.*

</div>

<br>

<details>
<summary><b>PASSO 01 — CLONAR O REPOSITÓRIO</b></summary>

<br>

```bash
git clone https://github.com/AndressaPapini/Sistemas-Celulares.git
```

</details>

<br>

<details>
<summary><b>PASSO 02 — ACESSAR A PASTA</b></summary>

<br>

```bash
cd Sistemas-Celulares
cd sistema_celulares_flask_desafio
```

</details>

<br>

<details>
<summary><b>PASSO 03 — CONFIGURAR O AMBIENTE</b></summary>

<br>

Crie um ambiente virtual:

```bash
python -m venv venv
```

Ative no Windows:

```bash
venv\Scripts\activate
```

Caso exista um arquivo `requirements.txt`, instale as dependências:

```bash
pip install -r requirements.txt
```

</details>

<br>

<details>
<summary><b>PASSO 04 — INICIAR A APLICAÇÃO</b></summary>

<br>

Configure o banco de dados conforme as definições do projeto.

Se o arquivo principal for `app.py`, execute:

```bash
python app.py
```

Acesse o endereço informado no terminal.

</details>
